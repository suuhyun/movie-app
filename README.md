## 📝 Overview
This is a **React-based movie application** styled with **Tailwind CSS**, designed to provide an IMDb-like platform for exploring movie details. Built using **The Movie Database (TMDB) API**.  
The app allows users to:
- 🎥 Browse and search for movies
- 📽️ Watch trailers
- 📝 View detailed information such as reviews, recommendations, and genre-based filters.

---

## ✨ Features

### 1. **🎥 TMDB API Integration**
- Fully integrated with the **TMDB API** to fetch real-time movie data.
- Includes features such as popular movies, genres, reviews, and recommendations.

### 2. **🔄 Infinite Scroll**
- Utilizes **React Query** to implement infinite scroll, enabling smooth browsing of large datasets without reloading.

### 3. **🔍 Movie Search**
- Allows users to search for movies by title.
- Results are sorted by **popularity**, ensuring a seamless user experience.

### 4. **🎭 Genre-Based Filtering**
- Users can filter movies based on genres, making it easier to find movies of interest.

### 5. **📄 Detailed Movie Pages**
Each movie has a dedicated page displaying:
- 🎬 Title and tagline
- 🎭 Genre tags
- ⏱️ Runtime
- 📅 Release date
- 📝 Synopsis
- 💰 Budget and revenue
- ⭐ Average ratings

### 6. **🤝 Recommendations**
- Users are shown similar movie recommendations based on the current movie.

### 7. **▶️ YouTube Trailer Integration**
- Trailers are directly accessible via YouTube by clicking the **Trailer** button.

### 8. **📱 Responsive UI**
- Built with **Tailwind CSS**, ensuring a responsive and modern design across all devices.

---

## 🛠️ Technologies Used

- **⚛️ React**: Core framework for building the app.
- **🔄 React Query**: For data fetching, caching, and state management.
- **🎥 TMDB API**: To fetch real-time movie data, reviews, and recommendations.
- **🎨 Tailwind CSS**: For responsive and clean UI styling.
